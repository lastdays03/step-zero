## 1. 계획 분석 요약

| 항목 | 내용 |
|------|------|
| **총 공수** | 28.5일 (약 5.5주) |
| **Section A** | BE 기반 구축 (5.5일) — DB 모델, 마이그레이션, ContextBuilder, SemanticRouter, Repository |
| **Section B** | BE 핵심 (7일) — ChatService(SSE 스트리밍), SSE 라우터, 안전장치 프롬프트 |
| **Section C** | FE 구현 (8일) — useStepChat Hook, StepChatPanel, 출처 UI, 통합, 모바일 |
| **Section D** | 품질 검증 (8일) — 프롬프트 튜닝, 안전장치 QA 100건+, 통합 테스트 |

**핵심 기술 포인트:**
- SSE(Server-Sent Events) 토큰 단위 실시간 스트리밍
- 3레이어 시스템 프롬프트 (팩트 / 상태 / 규칙)
- 로드맵 단계별 컨텍스트 인식 AI 대화
- 4가지 안전장치 (팩트-지능 분리, 출처 인용, 범위 제한, 면책 문구)

**코드베이스 현황:** 기존 RAG 채팅(~450 LOC) + 로드맵 서비스(~2,303 LOC) + 프론트 챗봇(~433 LOC)을 85%+ 재활용 가능. 새 패키지 추가 불필요.

**마이그레이션 번호 수정:** 계획서에는 011이라 되어 있으나, 현재 최신이 `011_template_startup_type.py`이므로 **012**로 수정 필요.

## 2. 의존성 그래프 & 병렬화 분석

```
                    ┌─────────────────────────────┐
                    │ Track 1: 데이터 인프라       │

                    │ A-1(모델) → A-2(마이그) →    │
                    │ A-5(Repo) → B-2(SSE 라우터)  │
                    └──────────┬──────────────────┘
                               │ B-1 합류점
                               ▼
┌──────────────────────────────┤
│ Track 2: AI 로직             │

│ A-4(SemanticRouter) ─────┘   │
└──────────────────────────────┤
                               ▼
                    ┌──────────────────────────────┐
                    │ Track 3: 프론트엔드          │
                    │ fe-dev                       │
                    │ C-2(스켈레톤, 즉시) →        │
                    │ C-1(Hook, B-2 후) →          │
                    │ C-3/C-4/C-5/C-6             │
                    └──────────────────────────────┘

                    ┌──────────────────────────────┐
                    │ Track 4: 품질 보증           │

                    │ 테스트 시나리오(즉시) →       │

                    └──────────────────────────────┘
```
