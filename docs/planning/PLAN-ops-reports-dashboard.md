# PLAN: Ops Reports Dashboard

## Status
- Draft

## 목적
- `/ops/reports`에서 운영 핵심 지표를 일관된 기준으로 조회할 수 있는 최소 대시보드를 구현한다.

## 범위
1. KPI 카드(활성 사용자, 신규 가입, 로드맵 생성)
2. 기간 필터(7일/30일)
3. 지표 생성 시각/기준 명시
4. 향후 확장 지표 슬롯 정의

## 비범위 (이번 단계)
- 복잡한 차트 분석/드릴다운
- 외부 BI 연동

## IA/화면 구성
1. 상단 필터
- 기간 선택, 새로고침
2. KPI 카드 영역
- 핵심 3~5개 지표
3. 보조 영역
- 최근 운영 이벤트 요약(선택)

## API 작업
### 현재
- `GET /api/v1/ops/reports/summary` (placeholder)

### 추가 필요
1. `GET /api/v1/ops/reports/summary?range=7d|30d`
2. (선택) `GET /api/v1/ops/reports/timeseries`

## 감사로그 정책
- 조회형 화면이므로 기본 감사로그 대상 아님
- 단, 민감 지표 접근 추적이 필요하면 `REPORT_VIEWED` 이벤트 도입 검토

## 구현 단계
1. 지표 정의 고정(집계 기준 문서화)
2. 백엔드 실집계 쿼리 반영
3. 프론트 카드/필터 구현
4. 데이터 없음/집계 실패 상태 정리

## 완료 기준 (DoD)
1. 운영자가 기간별 KPI를 안정적으로 조회할 수 있다.
2. 지표 기준/생성 시각이 화면에 명시된다.
