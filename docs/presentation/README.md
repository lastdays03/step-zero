# StepZero Presentation

This directory contains the Slidev presentation for StepZero service planning.

## How to Run

1.  Navigate to this directory:
    ```bash
    cd presentation
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    pnpm install
    ```

3.  Start the presentation server:
    ```bash
    npm run dev
    # or
    pnpm run dev
    ```

4.  Open http://localhost:3030 in your browser.

## Exporting

To export to PDF or other formats:

```bash
npm run export
```
