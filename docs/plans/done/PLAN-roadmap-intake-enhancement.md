# PLAN-roadmap-intake-enhancement

## 목적
- 로드맵 생성 시 필수 정보 외 추가 정보를 단계적으로 확장해 품질을 높인다.

## 현재 반영(필수)
- 업종
- 지역
- 창업 형태(개인사업자/법인/미정)
- 오픈 목표 시점
- 초기 예산 범위

## 추후 확장(2순위)
- 타겟 고객(연령/직군/소득대)
- 판매 채널(오프라인/온라인/배달앱/자사몰)
- 점포 형태(임대/공유주방/무점포)
- 보유 자원(경력/자격증/기존 고객/파트너)
- 현재 진행 단계(아이디어/시장조사/상권검토/인허가 진행중)

## 추후 확장(3순위)
- 규제 민감도 항목(식품위생/주류/의료/교육/개인정보)
- 지역 세부 행정구역 및 상권 후보
- 운영 시간/인력 계획
- 수익모델(상품판매/구독/광고/중개)
- 경쟁 강도 인식

## 적용 원칙
1. 질문 수가 과도해지지 않도록 적응형(조건부) 질문으로 확장한다.
2. 신규 질문 추가 시 생성 payload의 `description` 구조화 포맷을 유지한다.
3. 프론트 입력 확장 전 검증/생성 백엔드 수용 여부를 먼저 점검한다.
