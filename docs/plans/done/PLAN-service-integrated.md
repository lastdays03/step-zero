# StepZero 통합 서비스 기획서 (2026-02-13 회의 반영)

## 1. 기획 배경

예비 창업자는 정보가 부족해서가 아니라, 지금 내 상황에 맞는 정보를 제때 찾지 못해서 실행이 멈춥니다.  
StepZero는 이 문제를 다음 3축으로 해결합니다.

- 선제적 큐레이션 및 해설: 로드맵 단계에 맞는 법령, 공고문, 양식을 AI가 먼저 제시
- AI 기반 지능형 서류 작성: 반려 위험이 높은 핵심 문구를 정확하게 초안화
- 맥락형 커뮤니티: 지역/업종 기반 연결로 실전 정보의 신뢰도와 실행률 강화

## 2. 제품 비전

StepZero는 "창업 준비용 검색 도구"가 아니라, "실행형 창업 운영체계(Business Execution OS)"를 목표로 합니다.

- AI가 다음 행동을 제안한다
- 사용자는 바로 제출 가능한 결과물을 만든다
- 커뮤니티가 실행을 끝까지 밀어준다

## 3. 핵심 문제와 해결 전략

### 3.1 해결하려는 문제

- 절차 순서가 불명확해 시작 단계에서 이탈
- 법령/행정 정보의 신뢰성 검증 비용 과다
- 서류 작성 전문성 부족으로 반려/보완 요청 발생
- 혼자 준비하며 동기 저하 및 실행 지연

### 3.2 StepZero 전략

1. 선제형 로드맵: 검색 전에 "지금 할 일"을 먼저 제공
2. 근거형 안내: 법령/공고/별지서식 원문 기반 답변
3. 작성 자동화: 업종/상황별 문서 초안과 수정 루프 제공
4. 그룹 실행: 지역+업종 커뮤니티로 질의응답과 동기 유지

## 4. 서비스 구조

### 4.1 로드맵 + 선제적 큐레이션/해설

- 사용자 입력: 지역, 업종, 창업 유형, 현재 단계
- 출력:
  - 단계별 액션 목록
  - 단계별 필수 법령/행정규칙/공고문
  - 단계별 제출 서류/서식 템플릿
- 해설 방식:
  - 로드맵 페이지 내 챗봇으로 "현재 단계 맥락"을 유지한 질의응답
  - 원문 근거 위치와 요약 해설 동시 제공

### 4.2 AI 기반 지능형 서류 작성

- 기능 범위:
  - 초안 작성: 사업 목적, 사업 개요, 지원사업 신청서 핵심 문항
  - 수정 작성: 톤/분량/기관 요구사항에 맞춘 재작성
  - 저장/버전 관리: 단계별 작성본 히스토리
- 핵심 가치:
  - 법적/행정 문구의 전문성 보완
  - 반려 확률 감소 및 제출 품질 표준화

### 4.3 액션키트(Action Kit) 구성

- 법률:
  - 관련 법률/행정규칙
  - 별지서식 원본 및 작성 예시
- 세무:
  - 핵심 신고 항목 요약
  - 신고 기간 캘린더형 안내
- 공고:
  - 창업지원, 대출, 정책자금, 지자체 사업
  - 지역/업종/업력 조건별 필터링
- HR:
  - 업종별 근로계약서
  - 필수 노무 양식 묶음

## 5. 커뮤니티 전략 (커뮤니티 3안 통합)

### 5.1 핵심 컨셉: Dual-Group System

가입 시 `지역`과 `업종`을 필수 입력받고, 사용자를 자동으로 2개 그룹에 배정합니다.

- 지역 라운지: 로컬 행정/상권/지원사업 중심
- 업종 라운지: 실무 운영 노하우/원가/인력 이슈 중심

### 5.2 화면/경험 설계

- 왼쪽: 스마트 사이드바
  - 내 명찰(지역/업종 배지)
  - 우리 동네 그룹
  - 내 업종 그룹
  - 전체 광장(세무/노무 공통)
- 가운데: 맥락형 피드
  - 탭: 전체 / 동네 소식 / 업종 이야기
  - 게시글 자동 태깅(지역, 업종)
- 오른쪽: 연결 위젯
  - 내 주변 동료
  - 업종 멘토 추천
  - 맞춤 지원사업 배너

### 5.3 운영 기능

- 주간 베스트 글 / 유저 랭킹
- 좋아요/저장/스크랩
- 회원 등급:
  - 예비창업자
  - 창업자
  - 우수창업자
- 신뢰 체계(점진 도입):
  - 사업자/지역 인증 배지
  - 인증 사용자 전용 게시판

## 6. 데이터/매핑 설계 원칙

회의 핵심 과제인 "로드맵 단계별 업종 맞춤 양식 매핑"을 위해 다음 구조를 기본으로 설계합니다.

- 마스터 테이블:
  - `industries` (업종 분류)
  - `regions` (지역 분류)
  - `roadmap_steps` (단계 정의)
  - `documents` (법령/공고/양식 메타)
- 연결 테이블:
  - `step_document_mappings`
    - step_id
    - industry_id (nullable)
    - region_id (nullable)
    - document_id
    - priority
    - required_flag
- 커뮤니티 핵심 테이블:
  - `profiles` (region_id, industry_id, level, verified)
  - `posts` (target_region_id, target_industry_id, likes)
  - `weekly_rankings`

이 구조로 "공통 문서 + 업종 특화 문서 + 지역 특화 공고"를 한 단계에서 함께 노출할 수 있습니다.

## 7. 단계별 실행 로드맵

### Phase 1 (MVP, 1-2개월)

- 로드맵 생성 + 단계별 큐레이션
- 로드맵 내 챗봇 해설
- 액션키트 1차(법률/세무 핵심)
- 커뮤니티 기본(지역/업종 자동 그룹, 게시글, 좋아요)

### Phase 2 (Beta, 3-4개월)

- AI 서류 작성(초안/수정/저장)
- 공고 매칭 고도화(지역/업종/업력 조건)
- 주간 베스트/회원 등급/멘토 추천
- 인증 배지 체계 도입

### Phase 3 (Scale, 5개월+)

- OCR 및 제출서류 자동 검토
- 다중 에이전트(세무/노무/법무)
- 고도화 커뮤니티(전문가 세션, 폐쇄형 문제해결 그룹)
- 파트너 연계(B2B 전문가/서비스 마켓)

## 8. 핵심 KPI

- 로드맵 생성 후 7일 내 첫 액션 수행률
- 액션키트 문서 다운로드 후 제출 완료율
- AI 서류 작성 사용자의 반려율 감소폭
- 지역/업종 그룹 주간 활성도(WAU, 게시글/댓글 비율)
- 주간 베스트 참여율 및 재방문율

## 9. 결론

StepZero의 본질은 "정확한 정보 제공"이 아니라 "제출 가능한 결과물까지 만드는 실행 지원"입니다.  
이번 개편안은 로드맵, AI 문서 작성, 지역/업종 커뮤니티를 하나의 흐름으로 통합해 실제 창업 성공 확률을 높이는 데 초점을 둡니다.
