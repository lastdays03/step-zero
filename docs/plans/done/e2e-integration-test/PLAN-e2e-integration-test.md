# PLAN: Playwright MCP E2E 통합 테스트

> 전체 기능 브라우저 통합 테스트 (Playwright MCP)

## 목표
- 모든 사용자 플로우를 브라우저에서 실제로 검증
- API 응답, UI 렌더링, 에러 처리까지 End-to-End 확인

## 사전 조건
- Backend (port 8000) + Frontend (port 3000) + ARQ Worker 실행
- 원격 DB/Redis (193.122.102.216) 연결
- `ENABLE_SOCIAL_MOCK=true`

---

## 테스트 시나리오 (총 8개 영역, 26개 케이스)

### Phase 1: 인증 (Auth) — 3 케이스
| # | 시나리오 | 검증 포인트 |
|---|---------|------------|
| 1-1 | 소셜 목 로그인 | 토큰 발급, 대시보드 리다이렉트, 사용자명 표시 |
| 1-2 | 로그아웃 | 토큰 삭제, 로그인 페이지 이동, 보호 페이지 접근 차단 |
| 1-3 | 세션 만료 → 자동 갱신 | 만료 토큰 → silent refresh → API 재시도 성공 |

### Phase 2: 대시보드 (Dashboard) — 2 케이스
| # | 시나리오 | 검증 포인트 |
|---|---------|------------|
| 2-1 | Cold start (로드맵 없음) | ColdStartHero 표시, "로드맵 만들기" CTA |
| 2-2 | 로드맵 있을 때 대시보드 | 진행도 카드, 로드맵 스텝퍼, 그로스 클럽 소식 |

### Phase 3: 로드맵 생성 (핵심) — 5 케이스
| # | 시나리오 | 검증 포인트 |
|---|---------|------------|
| 3-1 | 정보 수집 (질문/응답) | 업종 선택 → 지역 → 형태 → 방식 → 예산 순서대로 진행 |
| 3-2 | 입력값 검증 | POST /validate → 정규화 결과 표시 |
| 3-3 | 비동기 생성 시작 | POST /jobs → 202, 상태 폴링 UI (프로그레스바) |
| 3-4 | 생성 완료 → 로드맵 뷰 | 단계/액션 렌더링, 제목 표시 |
| 3-5 | 로드맵 실행 (체크리스트) | 액션 체크/해제, 단계 상태 변경 (COMPLETED) |

### Phase 4: 프로필 (Profile) — 3 케이스
| # | 시나리오 | 검증 포인트 |

| 4-3 | 프로필 이미지 업로드 | 파일 선택 → POST /me/image → 이미지 표시 |

### Phase 5: 액션키트 (ActionKit) — 3 케이스
| # | 시나리오 | 검증 포인트 |
|---|---------|------------|

### Phase 6: 그로스 클럽 (Community) — 4 케이스
| # | 시나리오 | 검증 포인트 |

### Phase 7: AI 채팅 (Chat FAB) — 3 케이스
| # | 시나리오 | 검증 포인트 |

### Phase 8: 네비게이션 & 공통 — 3 케이스

|---|---------|------------|

## 실행 순서

```
Phase 1 (인증) → Phase 2 (대시보드) → Phase 3 (로드맵)
→ Phase 4 (프로필) → Phase 5 (액션키트) → Phase 6 (그로스클럽)
→ Phase 7 (AI 채팅) → Phase 8 (공통)
```

## 스킵 조건
- Phase 3-3/3-4: ARQ 워커 미실행 시 스킵
- Phase 7-2/7-3: OpenAI API 키 없을 시 스킵
- Ops 관리자 페이지: superuser 계정 필요 → 별도 테스트

- Phase 3: ~5분 (비동기 생성 대기 포함)
- Phase 4~8: ~7분
