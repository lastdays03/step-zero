> 작성일: 2026-02-28
> 작성: roadmap-improvement 기획팀 (5명 분석 종합)
> 상태: v1.0 — 초안 완성

---

## 1. Executive Summary

Step Zero의 로드맵은 **ActionKit 법률 DB 기반의 검증된 법적 근거 + 구조화된 실행 관리**라는 핵심 경쟁력을 보유하고 있다. 이것은 ChatGPT/Gemini가 아키텍처적으로 제공할 수 없는 고유 가치이다.

그러나 현재 로드맵은 **"한 번 생성하고 끝나는 정적 리포트"**에 가까워, 사용자가 Step Zero에서 로드맵을 받은 뒤 → 후속 질문을 ChatGPT에서 하는 **이중 사용 패턴**에 빠질 위험이 높다.

**핵심 전환 방향:**

> "ChatGPT는 질문하면 답해주는 도구. Step Zero는 함께 걸어가는 동반자."

이 기획서는 Step Zero를 **정적 리포트 생성기 → 동적 창업 실행 코치**로 전환하기 위한 구체적 개선 과제를 제시한다.

## 2. 현재 상태 진단 (As-Is)

### 2.1 핵심 강점 (유지/강화)

| 강점 | 상세 | ChatGPT 대비 |
|------|------|-------------|
| **ActionKit 법률 DB 통합** | 벡터 검색 + 관계형 DB JOIN으로 검증된 법령/양식 매칭. 법령명+조문+파일 경로의 traceability 확보 | ChatGPT 법률 정보 오류율 43% (Stanford 연구) vs ActionKit DB 검증 |
| **팩트-지능 분리 아키텍처** | "ActionKit 법령명/파일 경로는 절대 수정 불가" 규칙으로 LLM 할루시네이션 구조적 차단 | ChatGPT는 법률명을 그럴듯하게 지어냄 |
| **구조화된 실행 관리** | 순차적 진행 강제, 자동 진행, 되돌리기, 액션 자동 완료 | ChatGPT 답변은 "읽고 끝", 진행 추적 불가 |
| **3+1 계층 데이터 모델** | Roadmap → Step → Detail + Action 구조로 풍부한 메타데이터 + 품질 추적 | ChatGPT는 비구조화 텍스트만 생성 |
| **다층 폴백 전략** | ActionKit → RAG → 템플릿 기반 3단계 폴백으로 서비스 중단 없는 생성 보장 | 해당 없음 |
| **MappingSource 투명성** | "법령 기반" / "AI 분석" / "일반 안내" 배지로 정보 출처 신뢰도 표시 | ChatGPT는 출처 불명 |

### 2.2 핵심 약점 (개선 필요)

| 약점 | 이탈 위험도 | 상세 |
|------|-----------|------|
| **일회성 생성** | ★★★★★ | 생성 후 재생성/부분 업데이트 불가. 예산이 바뀌면 처음부터 다시 만들어야 함 |
| **생성 후 인터랙션 부재** | ★★★★★ | AI와의 후속 대화 불가. "이 법령이 뭔지 설명해줘" → 불가능. ChatGPT로 이탈 유발 |
| **재방문 동기 없음** | ★★★★ | 알림, 리마인더, 마감 알림, 성취감 보상 메커니즘 전무 |
| **업종 커버리지 한계** | ★★★★ | 우선 매칭 업종 8개 제한. IT/제조/의료 등 비전통 업종은 ActionKit 미활용 |
| **개인화 깊이 부족** | ★★★ | 6개 입력 필드만 수집. 팀 규모, 기존 완료 절차, 특수 상황(청년/외국인 창업) 미반영 |
| **정적 콘텐츠** | ★★★ | 법률 변경 시 기존 로드맵 반영 메커니즘 없음 |
| **고립된 경험** | ★★ | 커뮤니티, 동료 비교, 멘토링 연결 없음 |

## 3. 경쟁 환경 분석

### 3.1 ChatGPT/Gemini vs Step Zero

| 평가 항목 | ChatGPT/Gemini | Step Zero |
|----------|---------------|-----------|
| 법률 정보 정확성 | ❌ 오류율 43%, 존재하지 않는 판례 인용 75%+ | ✅ ActionKit DB 검증, 출처 URL 제공 |
| 한국 특화 | ❌ 미국/서구 중심, 한국 규제 세부사항 미반영 | ✅ 식품위생법, 구청별 편차, 위생교육 의무 등 반영 |
| 실행 추적 | ❌ 대화 끝나면 끝. 진행 관리 불가 | ✅ 상태 관리, 자동 진행, 진행률 대시보드 |
| 개인화 | ⚠️ 프롬프트 의존, 일관성 없음 | ✅ 6개 변수 + ActionKit 매칭으로 구조적 개인화 |
| 후속 질문 | ✅ 무제한 대화 가능 | ❌ **현재 불가 (최대 약점)** |
| 비용 | 무료~월 2만원 | 유료 (포지셔닝 필요) |

### 3.2 기존 공공 서비스

| 서비스 | 강점 | Step Zero 대비 약점 |
|--------|------|-------------------|
| 소상공인마당 | 157개 업종별 창업절차도, 법적 정확성 | 정적 콘텐츠, AI 없음, 개인화 없음, UI 구식 |
| K-Startup | 지원사업 통합 정보 | 소상공인 대상 미흡, 로드맵 없음 |
| 창업진흥원 | 예비창업패키지 등 지원사업 | AI 가이드 없음 |

### 3.3 핵심 포지셔닝

> **"개인 창업자의 프랜차이즈 본사"**
> 행정사 비용(20~100만원)의 1/10 가격에, 검증된 법률 DB 기반으로 AI 컨설턴트가 창업 전 과정을 함께 실행하는 서비스

**1문장 차별화:**

> "ChatGPT는 '뭘 해야 하는지' 알려주고, Step Zero는 '지금 이걸 하세요'라고 실행시켜 줍니다."

## 4. 핵심 차별화 전략 (To-Be)

### 4.1 전략 프레임워크: 3T

| 전략 축 | 설명 | ChatGPT가 못하는 이유 |
|---------|------|---------------------|
| **Trust (신뢰)** | ActionKit DB = 할루시네이션 없는 법률 정보 | ChatGPT는 법률명을 43% 확률로 틀림 |
| **Track (추적)** | 진행률 대시보드 + 자동 완료 + 리마인더 | ChatGPT는 세션 단위, 상태 기억 불가 |
| **Trend (트렌드)** | 데이터 축적 → 업종별 인사이트 → Data Moat | ChatGPT는 세션 간 학습 안 함 |

### 4.2 5가지 핵심 차별 요소

1. **지속적 상태 추적**: 내 진행 상황을 기억하고 다음을 알려줌
2. **적시 알림**: 내가 찾아가지 않아도 필요할 때 알려줌
3. **검증된 법령 데이터**: 할루시네이션 없는 법률/양식 정보
4. **구조화된 실행**: 순서대로, 빠짐없이, 체크하며 진행
5. **동기 부여**: 성취감, 벤치마크, 스트릭으로 계속 나아가게 함

## 5. 구체적 개선 과제 목록

### Phase 1: Quick Win (1-3주) — "즉각적 가치 전달"

#### 과제 1-1. 마일스톤 축하 모먼트
- **설명**: Phase 완료 시 축하 애니메이션 + AI 격려 메시지 표시. "축하합니다! '시장 조사' 단계를 완료했습니다."
- **기대효과**: 즉각적 감정 보상 → 다음 단계 진행 동기. Duolingo 연구에서 보상이 참여도 3.6배 향상
- **구현 난이도**: Low
- **예상 기간**: 3-5일
- **DB 변경**: 없음

#### 과제 1-2. 창업 준비도 스코어
- **설명**: 전체 로드맵 완료율 + 체크리스트 완료도 + 법적 근거 확인 여부를 종합한 점수. "초보 → 준비중 → 숙련 → 전문가" 레벨 시스템
- **기대효과**: LinkedIn 프로필 강도 미터 패턴 — 프로필 완성률 55% 향상 검증됨
- **구현 난이도**: Low
- **예상 기간**: 3-5일
- **DB 변경**: 없음 (기존 진행률 데이터 재가공)

#### 과제 1-3. 업종별 벤치마크 데이터 (기본)
- **설명**: "카페 창업자 평균 소요시간", "87%가 이 단계에서 가장 어려움을 느꼈습니다" 같은 집계 인사이트
- **기대효과**: 소셜 프루프 효과 + 데이터 네트워크 효과의 시작점
- **구현 난이도**: Low
- **예상 기간**: 1주
- **DB 변경**: Optional (materialized view 또는 Redis 캐시)

#### 과제 1-4. 성능 최적화 (캐싱)
- **설명**: 동일 업종+지역 조합의 ActionKit 매칭 결과를 Redis 캐싱하여 생성 시간 단축
- **기대효과**: 생성 체감 속도 대폭 개선
- **구현 난이도**: Low
- **예상 기간**: 1주
- **DB 변경**: 없음

---

### Phase 2: 핵심 차별화 (2-4주) — "ChatGPT로 이탈 차단"

#### 과제 2-1. 단계별 AI 코치 대화 (핵심!)
- **설명**: 각 단계에서 "AI에게 물어보기" 버튼 → 현재 단계의 맥락(업종/지역/법령)을 기반으로 AI가 구체적 실행 가이드 제공. SSE 스트리밍 지원
- **기대효과**: **ChatGPT 이탈 방지의 핵심**. 맥락이 이미 로드맵에 있으므로 재설명 불필요
- **구현 난이도**: Medium
- **예상 기간**: 2-3주
- **DB 변경**: 필요 (chat_thread, chat_message 테이블)
- **코드 재활용**: 기존 ChatService, RagService, SemanticRouter 80%+ 재활용 가능
- **기술 상세**:
  - `POST /api/v1/roadmaps/{id}/steps/{step_id}/chat/stream` (SSE)
  - 시스템 프롬프트에 해당 단계의 checklist, legal_basis, documents 주입
  - ActionKit 팩트 데이터를 답변 근거로 활용

#### 과제 2-2. 로드맵 부분 재생성
- **설명**: 특정 단계만 업데이트하거나, 조건 변경(예산/오픈시기) 시 영향받는 단계만 재생성
- **기대효과**: "예산이 바뀌었는데 처음부터 다시?" → 부분 수정으로 해결
- **구현 난이도**: Medium
- **예상 기간**: 1-2주
- **DB 변경**: Minor (step 버전 트래킹 optional)
- **코드 재활용**: ActionKitMatcher, LLMPersonalizer 핵심 로직 그대로 사용
- **기술 상세**: `POST /api/v1/roadmaps/{id}/steps/{step_id}/regenerate`

#### 과제 2-3. 프로액티브 리스크 알림 + 넛지
- **설명**: "3일째 '사업자등록' 단계에 머물러 있습니다. 마감까지 4일 남았습니다." 형태의 적시 알림. 이메일 + 인앱 알림
- **기대효과**: 장기간 미접속 사용자 재유입. Monday.com의 일일 리스크 스캔 패턴
- **구현 난이도**: Medium
- **예상 기간**: 2-3주
- **DB 변경**: Minor (reminder_at 필드, 알림 type 확장)

#### 과제 2-4. 주간 진행 서머리 이메일
- **설명**: 매주 "이번 주 진행률, 완료 항목, 다음 주 목표" 이메일 발송
- **기대효과**: 재방문 트리거. 프로액티브 푸시로 "사용하지 않아도 가치 전달"
- **구현 난이도**: Medium
- **예상 기간**: 2주
- **DB 변경**: Minor (이메일 발송 이력)

### Phase 3: 성장 엔진 (4-8주) — "경쟁사가 따라올 수 없는 해자"

#### 과제 3-1. 스텝별 마이크로 가이드
- **설명**: 각 체크리스트/서류 액션에 "방법 보기" 접기/펼치기 → 3-5줄 실행 가이드 + 관련 링크/양식 다운로드
- **기대효과**: "어떻게 하지?" → 외부 검색 이탈 방지. ActionKit 데이터의 심층 활용
- **구현 난이도**: Medium-High
- **예상 기간**: 3-4주
- **DB 변경**: Optional (가이드 콘텐츠 테이블 또는 ActionKit 확장)

#### 과제 3-2. ActionKit 업데이트 시 자동 알림
- **설명**: 법률 변경 감지 → 영향받는 로드맵 사용자에게 "관련 법률이 변경되었습니다" 알림 + 재생성 제안
- **기대효과**: 정적 콘텐츠 문제 해결. 지속적 신뢰 구축
- **구현 난이도**: Medium-High
- **예상 기간**: 2-3주
- **DB 변경**: Minor (actionkit_item_id 컬럼 승격 + 인덱스, 변경 이력)
- **기술 상세**: metadata_json.actionkit_item_id 기반 역추적 → Notification 모델 재활용

#### 과제 3-3. 팀 협업 기능
- **설명**: 단계별 담당자 할당, 코멘트, 역할 기반 권한 (owner/editor/viewer)
- **기대효과**: 팀 창업 시나리오 지원. 팀 내 락인 효과
- **구현 난이도**: Medium-High
- **예상 기간**: 3-4주
- **DB 변경**: 필요 (step_assignee, step_comment, activity_log 테이블)
- **코드 재활용**: team_id 기반 멀티테넌시 이미 전 계층에 구현 → 60% 재활용

#### 과제 3-4. 캘린더/리마인더 연동
- **설명**: estimated_days 기반 .ics 파일 다운로드 (Phase 1) → 인앱 리마인더 (Phase 2) → Google Calendar 연동 (Phase 3)
- **기대효과**: 외부 도구와 연결하여 일상 워크플로에 통합
- **구현 난이도**: Low(Phase 1) ~ High(Phase 3)
- **예상 기간**: 1주(Phase 1) ~ 5주(전체)
- **DB 변경**: Minor (reminder_at)

#### 과제 3-5. 주간 활동 스트릭
- **설명**: 매주 최소 1개 체크리스트 완료 시 스트릭 유지. 스트릭 프리즈(1주 쉬어도 유지) 포함
- **기대효과**: Duolingo 검증 — 7일 스트릭 유지 사용자의 장기 참여 가능성 3.6배
- **구현 난이도**: Medium
- **예상 기간**: 2주
- **DB 변경**: 필요 (user_streak 테이블)

Phase 2: 핵심 차별화 (Week 4-8)

## 7. 수익화 전략

### 7.1 Tier 구조

| Tier | 가격 | 포함 내용 |
|------|------|----------|
| **Free** | 0원 | 로드맵 1개, 기본 체크리스트, 법적 근거 3개까지 |
| **Starter** | 월 19,900원 | 로드맵 3개, 전체 ActionKit 접근, 진행률 리포트, 마감일 알림 |
| **Pro** | 월 39,900원 | 무제한 로드맵, AI 코치 대화, 벤치마크 인사이트, 정부 지원사업 매칭 |
| **건당 Premium** | 5~15만원 | 법인설립 셀프 패키지, 상표권 출원 가이드 등 |

### 7.2 가격 전략 핵심

- **"행정사 1번 비용 = Step Zero 1년 비용"** — 행정사 인허가 대행 20~100만원 vs Starter 연 24만원
- 창업 준비 기간(3~6개월) 고려 시 LTV: 6~12만원 (Starter) ~ 24~48만원 (Pro)
- Free 체험 → 법적 근거 상세 열람부터 유료 전환 (핵심 가치에서 페이월)

### 7.3 추가 수익원

| 수익원 | 시기 | 방식 |
|--------|------|------|
| 전문가 연결 수수료 | 즉시 | 세무사/행정사/법무사 리드 생성 → 건당 수수료 |
| 데이터 인사이트 B2B | 중기 | 업종별 창업 트렌드 리포트 → 금융기관/정부 판매 |
| B2G 라이선스 | 중기 | 대학/지자체 창업지원단에 SaaS 판매 |
| 교육 콘텐츠 | 단기 | 업종별 창업 가이드 유료화 |
