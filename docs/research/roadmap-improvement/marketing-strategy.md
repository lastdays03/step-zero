# Step Zero 한국 시장 특화 마케팅 전략

> 작성일: 2026-02-28
> 담당: marketing-strategist (Task #8)
> 상태: v1.0

---

## Executive Summary

한국 창업 시장은 2024년 폐업 100만 건 돌파(사상 최초)라는 극적인 고통 지점을 내포하고 있다. Step Zero는 "정보 비대칭 해소 + AI 기반 실행 코치"라는 명확한 포지션으로, 소상공인마당·ChatGPT·행정사 모두를 대체하는 통합 솔루션으로 포지셔닝할 수 있다. 핵심 메시지 프레임: **"행정사 1번 비용으로 1년 내내 AI 파트너"**, 핵심 USP: **"ChatGPT는 틀릴 수 있다. Step Zero는 법으로 검증한다."**

---

## 1. 핵심 메시징 전략 (3단계 퍼널)

### 1단계: 인지 (Awareness) — "고통 인식"

**타겟 심리:** 창업을 꿈꾸지만 절차의 복잡성에 압도당하는 예비 창업자

| 채널 | 메시지 프레임 | 핵심 문구 |
|------|------------|---------|
| 뉴스/언론 기고 | 위기/공포 프레이밍 | "2024년 폐업 100만 건 — 3곳 중 2곳은 5년 내 문을 닫는다. 준비가 달랐다." |
| 네이버 SEO 콘텐츠 | 정보 갭 해소 | "카페 창업 절차 완전 가이드 — 인허가 빠뜨리면 개업도 못 한다" |
| 유튜브 프리롤 | 비교 프레이밍 | "소상공인마당 쓰다가 인허가 누락? AI가 빠짐없이 체크해 드립니다" |
| 블라인드 / 에브리타임 | 공감 프레이밍 | "창업 준비 10개월... 혼자 하면 뭘 빠뜨리는지도 모릅니다" |

**인지 단계 KPI:** 브랜드 검색량 월 500회, 랜딩 페이지 방문 월 2,000명 (Phase 1 목표)

---

### 2단계: 관심 (Consideration) — "비교와 검증"

**타겟 심리:** "소상공인마당이나 ChatGPT로 충분하지 않을까?" 의심하는 잠재 사용자

| 채널 | 메시지 프레임 | 핵심 문구 |
|------|------------|---------|
| 랜딩 페이지 히어로 | 직접 비교 | "소상공인마당: 정보 나열. ChatGPT: 43% 오류율. Step Zero: 법으로 검증된 실행 계획" |
| 유튜브 데모 영상 | 가치 시연 | "카페 창업 준비, AI가 17개 인허가를 빠짐없이 잡아주는 과정 (실사용 데모)" |
| 네이버 카페 기고 | 소셜 프루프 | "베타 사용자 후기: '행정사한테 갔다가 50만원 견적 받았는데 Step Zero에서 무료로 다 나왔어요'" |
| 정부 기관 협력 | 권위 부여 | "소진공 창업 교육 공식 추천 툴" (목표) |

**관심 단계 KPI:** 로드맵 체험 생성율 30%, 이메일 수집 전환율 20%

---

### 3단계: 전환 (Conversion) — "지불 결정"

**타겟 심리:** "가치는 알겠는데 월 2만원 내는 게 맞나?" 망설이는 사용자

**핵심 전환 프레임 3가지:**

#### 프레임 A: 비용 비교 앵커링
```
행정사 인허가 대행: 20~100만원 (1회)
Step Zero Starter: 월 19,900원 = 연 24만원
→ "행정사 1번 비용으로 10개월 내내 AI 파트너"
```

#### 프레임 B: 실패 방지 보험
```
"2024년 폐업 사업자의 37%가 초기 인허가 문제 경험"
(ActionKit 검증 + 법적 근거 배지 = 실수 0%)
→ "창업 실패 방지 보험, 월 19,900원"
```

#### 프레임 C: 진행 중 페이월 (Endowed Progress)
```
"지금까지 확인한 법적 근거 3/12개
나머지 9개 법령을 확인하려면 → Pro 업그레이드"
→ 가치를 체험한 뒤 자연스러운 전환 유도
```

**전환 단계 KPI:** 유료 전환율 5% (Phase 2), 첫 결제 후 90일 리텐션 80%+

## 2. 사용자 획득 채널 전략 (한국 특화)

|------|------|---------|-----------|--------|
| **네이버 SEO/블로그** | "카페 창업 절차", "음식점 인허가" 등 롱테일 키워드 공략. 업종별 상세 가이드 + 내부 링크로 Step Zero 체험 유도 | 5,000원~15,000원 | 3~5% | ★★★★★ |
| **카카오톡 알림톡** | 로드맵 생성 후 주간 진행 리마인더, 마감 알림. 90%+ 일일 사용률 활용. 재방문 최우선 채널 | 2,000원~5,000원 | 8~12% | ★★★★★ |
| **유튜브 창업 채널** | "창업 브이로그", "소자본 창업" 채널과 협업. 15초 데모 광고. 실제 로드맵 생성 과정 영상 | 8,000원~20,000원 | 2~4% | ★★★★☆ |
| **소진공/창진원 연계** | 예비창업패키지 교육 자료에 포함, 소진공 공식 채널 추천 요청. 정부 신뢰 활용 | 0원~3,000원 | 10~15% | ★★★★☆ |
| **블라인드/에브리타임** | "창업 준비 중" 게시판에 유기적 후기 배포. 진정성 있는 스토리텔링. 광고 아닌 커뮤니티 참여 | 1,000원~5,000원 | 5~8% | ★★★★☆ |
| **네이버 카페 (창업 커뮤니티)** | 창업나라, 자영업자모임 등 카페 내 유기적 참여. 질문에 가이드로 답변하며 자연스러운 툴 소개 | 1,000원~5,000원 | 4~7% | ★★★☆☆ |
| **인스타그램/틱톡** | 카드뉴스: "카페 창업 준비 17가지 체크리스트" + 링크. 릴스: 30초 로드맵 생성 데모 | 10,000원~25,000원 | 1~3% | ★★★☆☆ |
| **구글 검색 광고** | "창업 절차", "사업자등록 방법" 등 고의도 키워드. 경쟁 낮고 전환 의도 높음 | 15,000원~30,000원 | 3~6% | ★★★☆☆ |

### 카카오톡 채널 전략 (특별 강조)

한국 소비자의 이메일 오픈율 15% 미만 vs 카카오 알림톡 오픈율 85%+ 를 감안하면, 카카오톡은 단순 알림 채널이 아닌 핵심 재방문 엔진이다.

**카카오톡 활용 시나리오:**
- **온보딩**: 로드맵 생성 완료 시 → "Step Zero 채널 추가하고 주간 리마인더 받기"
- **재방문 트리거**: 매주 월요일 → "이번 주 할 일 3가지: ①음식위생교육 신청..."
- **마감 알림**: 기한 3일 전 → "사업자등록 신청 마감 D-3. 지금 바로 확인하세요"
- **전환 넛지**: 페이월 도달 시 → "AI 코치에게 지금 바로 물어보세요 (7일 무료 체험)"

## 3. Phase별 GTM 전략

### Phase 1: 무료 가치 입증 (Month 1~3)
**목표:** Free 사용자 1,000명, 브랜드 인지도 구축, 리텐션 메커니즘 검증

**핵심 GTM 활동:**

| 활동 | 방법 | 예산 | 기대 효과 |
|------|------|------|---------|
| 창업 커뮤니티 게릴라 마케팅 | 블라인드, 네이버 카페, 에브리타임에 실제 사용 후기 배포 | 0원 (시간 투자) | 200~300명 유입 |
| 업종별 가이드 SEO 콘텐츠 10편 | "카페 창업 완전 가이드", "음식점 인허가 7단계" 등 상위 노출 | 50만원 (외주/시간) | 500~800명 유입 |
| Product Hunt 등록 | 영문 버전 Product Hunt + 한국 스타트업 커뮤니티 공개 | 0원 | 100~200명 얼리어답터 |
| 베타 사용자 인터뷰 20건 | Zoom 인터뷰 → 후기 콘텐츠 → 소셜 배포 | 20만원 (커피 기프티콘) | 소셜 프루프 확보 |
| 소진공 창업 교육 협력 제안 | 소진공 담당자 컨택, 교육 자료 내 툴 소개 협력 요청 | 0원 | 신뢰도 + 정부 트래픽 |

**Phase 1 핵심 메시지:** "무료로 내 창업 로드맵을 AI가 만들어 드립니다. 5분이면 됩니다."

---

### Phase 2: 유료 전환 (Month 4~6)
**목표:** 유료 전환율 5%, MRR 500만원 (Starter 기준 250명)

**핵심 전환 트리거:**

1. **AI 코치 대화 출시** → "법령 기반 AI 코치 무료 3회 체험 후 유료 전환" 캠페인
2. **페이월 최적화** → 법적 근거 3개 열람 후 "나머지 9개 보기" CTA 최적화
3. **성공 사례 콘텐츠** → "Step Zero로 강남구 카페 45일 만에 개업한 이야기" 인터뷰 영상
4. **카카오톡 전환 캠페인** → 무료 로드맵 사용자 대상 "AI 코치 첫 달 50% 할인" 알림

**가격 앵커링 전략:**
```
랜딩 페이지에 비용 비교 테이블 상단 배치:
❌ 행정사 컨설팅: 50~100만원
❌ 소상공인마당: 정보 있음, 실행 안내 없음
❌ ChatGPT: 법률 오류율 43%
✅ Step Zero Starter: 월 19,900원 (법으로 검증된 실행 코치)
```

**Phase 2 채널 집중:**
- 구글/네이버 검색 광고 (전환 의도 높은 키워드)
- 유튜브 창업 채널 협찬 광고
- 카카오톡 알림톡 재활성화 캠페인
- 정부 연계 채널 (소진공, 창진원 공식 추천)

---

### Phase 3: B2B 확장 (Month 7~12)
**목표:** MRR 2,000만원, B2B 파이프라인 구축

**B2B 타겟 세그먼트:**

| 세그먼트 | 접근 방법 | 예상 계약 규모 | 우선순위 |
|---------|---------|------------|--------|
| **대학 창업지원단** (전국 200개+) | 창업진흥원 통해 대학 창업센터 일괄 계약 제안 | 학교당 월 50~200만원 | ★★★★★ |
| **지자체 창업지원센터** | 지역 창업센터 입주 기업 대상 SaaS 공급 | 센터당 월 30~100만원 | ★★★★☆ |
| **프랜차이즈 본사** (창업 지원 패키지) | 가맹 창업자에게 Step Zero 포함, 번들 판매 | 브랜드당 월 100~500만원 | ★★★★☆ |
| **금융기관** (창업 대출 심사 보조) | 창업 대출 신청자에게 Step Zero 로드맵 필수 제출 → 리드 제공 | 은행당 월 200~1,000만원 | ★★★☆☆ |
| **세무사/행정사 사무소** | 고객 창업 준비에 Step Zero 화이트레이블 제공 | 사무소당 월 30~100만원 | ★★★☆☆ |

**B2B GTM 전략:**
- 창진원 MOU 체결 → "공식 창업 준비 플랫폼" 타이틀 획득
- 대학 창업학과 교수 어드바이저 위촉 + 강의 자료 내 Step Zero 포함
- 프랜차이즈 박람회 참가 (COEX 프랜차이즈 서울 등)
- 업종별 B2B 데이터 인사이트 리포트 → 언론 배포 (PR + 리드 제너레이션)

### 4.3 성공 사례 콘텐츠 (소셜 프루프)

**3가지 스토리 아크:**

1. **"인허가 실수 방지"**: "혼자 준비했더라면 의약품 취급 허가를 몰랐을 텐데 — 편의점 창업자 박OO씨 이야기"
2. **"시간 절약"**: "행정사 상담 2달 vs Step Zero 3주 — 강남구 카페 박OO씨의 창업 타임라인"
3. **"비용 절감"**: "행정사 견적 70만원 받고 나왔다가 Step Zero로 돌아온 이야기"

## 5. 경쟁사 대비 포지셔닝 맵

```
법률 정확성
(높음)
│
│              ● Step Zero ← 목표 포지션
│              (고개인화 + 고정확성)
│
│    ● 소상공인마당
│    (저개인화 + 고정확성*)
│    *정적 법령 정보 기준
│
│                         ● ChatGPT/Gemini
│                         (고개인화* + 저정확성)
│                         *프롬프트 의존
│
│    ● 비즈넵
│    (중개인화 + 중정확성)
│    *세금 특화
│
└─────────────────────────────────────────────
     저개인화                           고개인화
     (일반화된 정보)                    (내 상황 특화)
```

**Step Zero만의 고유 영역:**
- 법률 정확성: ActionKit DB 기반, 할루시네이션 구조적 차단 → 법령 오류율 <5% (ChatGPT 43% 대비)
- 개인화 수준: 업종 + 지역 + 자본금 + 사업 형태 조합으로 수천 가지 조합의 맞춤 로드맵 → ChatGPT 프롬프트 의존 방식 대비 구조적 우위

**경쟁사별 차별화 메시지:**

| 경쟁사 | Step Zero 차별화 포인트 |
|--------|---------------------|
| 소상공인마당 | "법령 데이터는 같지만, 내 상황에 맞게 실행 순서를 만들어 준다 + AI가 질문에 답해 준다" |
| ChatGPT | "AI가 생성하는 것은 같지만, 한국 법령 DB 검증 + 내 창업 현황 저장 + 법이 바뀌면 알림" |
| 비즈넵 | "세금은 비즈넵, 창업 인허가는 Step Zero — 창업 전 과정의 AI 파트너" |
| 행정사 | "행정사가 하는 일의 80%를 Step Zero가, 나머지 20%는 연결된 행정사 파트너가" |

## 6. 바이럴/리퍼럴 메커니즘

### 6.1 공유 카드 시스템

**트리거 시점:**
- 로드맵 생성 완료 → "내 창업 로드맵 공유하기" 카드
- 단계 완료 → "카페 창업 5단계 완료! 전체 37% 달성" 진행률 카드
- 로드맵 완전 완료 → "드디어 창업 준비 완료! 143일의 기록" 성취 카드

**공유 카드 디자인 요소:**
- 업종 아이콘 + 진행률 그래프 시각화
- "Step Zero와 함께 준비했습니다" 브랜딩
- QR코드로 동일 업종 무료 체험 연결

**목표 바이럴 계수 (K-factor):** 0.3 이상 (사용자 10명당 3명 추가 유입)
