## Executive Summary

Step Zero의 6개 연구 문서와 브레인스토밍 결과를 종합한 **실행 가능한 제품 로드맵**이다.
핵심 방향: **"정적 리포트 생성기 → 동적 창업 실행 코치"** 전환을 16주(4개월) 안에 달성한다.

**3대 전략 축:**
1. **Phase 1 (Week 1-3)**: 비용 제로 Quick Win — 즉각적 UX 가치 전달
2. **Phase 2 (Week 4-8)**: ChatGPT 이탈 차단 — AI 코치 + 리텐션 엔진
3. **Phase 3 (Week 9-16)**: 경쟁사 불가능한 해자 — 법령 변경 알림 + 성장 엔진

## 2. Phase별 실행 계획 (Sprint 레벨)

### Phase 1: Quick Win (Week 1-3) — "즉각적 가치 전달"

> **목표**: 비용 제로로 초기 사용자 완료율 20-55% 향상 + 첫 5분 경험 혁신
> **리소스**: FE 집중 (BE 변경 없음)
> **Phase 1 MDP**: Endowed Progress + 다음 3단계 집중 + 준비도 스코어 (3개면 충분)

#### Sprint 1-A (Week 1, 5일)

| 작업 | 파일 | 공수 | 담당 |
|------|------|------|------|
| **Endowed Progress UI** — 로드맵 생성 직후 "18단계 중 3단계 이미 완료(17%)" 표시 | `RoadmapExecutionView.tsx`, `RoadmapSidebar.tsx` | 3일 | FE |
| **다음 3-5 액션 집중 표시** — 전체 목록 대신 현재 단계 + 다음 2개만 우선 표시 | `TimelineStepItem.tsx` | 2일 | FE |

**Sprint 1-A 완료 기준:**
- [ ] 로드맵 생성 시 "이미 17% 완료" 배지 표시
- [ ] 다음 3단계 외 나머지는 접혀있는 상태로 기본값 변경

#### Sprint 1-B (Week 2-3, 10일)

| 작업 | 파일 | 공수 | 담당 |
|------|------|------|------|

### Phase 2: 핵심 차별화 (Week 4-8) — "ChatGPT 이탈 차단"

> **목표**: AI 코치 대화 + 재방문 엔진 구축으로 WAU/MAU 35% 달성
> **리소스**: FE + BE 동시 진행, AI·ML 투입 시작
> **Phase 2 MDP**: AI 코치 대화 MVP + 주간 이메일 (이 2개면 핵심 목표 달성)

**의존성 순서:**
```
알림 인프라 구축 (Week 4) ──→ 주간 이메일 (Week 5) ──→ 카카오톡 (Week 7)
                                                      ↑
AI 코치 BE (Week 4-5) ──→ AI 코치 FE (Week 6) ────────┘
                                                  ↑
로드맵 부분 재생성 (Week 6) ─────────────────────────┘
프로액티브 알림 (Week 7) ────────────────────────────┘
.ics 캘린더 (Week 5) ───────────────────── 독립 병렬
주간 스트릭 (Week 8) ←── 알림 인프라 완료 후
```

#### Phase 3 Go/No-Go 기준

| 평가 항목 | Go 기준 | No-Go 액션 |
|----------|---------|-----------|

| 사용자 민원 (법률 오류) | 0건 | 즉시 중단 + 안전장치 재검토 |

## 4. 리소스 배분 계획

### Phase별 리소스 배분 (FE / BE / AI·ML)

| Phase | 기간 | FE | BE | AI·ML | 비고 |
|-------|------|----|----|-------|------|
| **Phase 1** | Week 1-3 | **80%** | 10% | 10% | UI 변경 집중, BE 개입 최소화 |
| **Phase 2** | Week 4-8 | 35% | **40%** | **25%** | AI 코치 개발 + 알림 인프라 구축 |
| **Phase 3** | Week 9-16 | 20% | **40%** | **40%** | 법령 변경 감지 + AI 매칭 엔진 |

## 5. MVP 범위 정의 (각 Phase의 MDP)

### Phase 1 MDP (Minimum Delightful Product)

**반드시 포함:**
- Endowed Progress ("이미 17% 완료")
- 다음 3단계 집중 표시 (전체 목록 기본값 접기)
- 준비도 5단계 스코어 (🌱→🚀)

**있으면 좋지만 필수 아님:**
- 마일스톤 축하 모먼트 (Phase 1 후반 추가)
- 첫 5분 경험 최적화 (RoadmapChatIntake 개선)

**포함 안 함:**
- 벤치마크 데이터 (초기에는 정적 숫자라도 의미 없음)
- 성능 캐싱 (Phase 2 이후)

**Phase 1 성공 기준:**
- 로드맵 생성 직후 이탈률 20% 감소 (측정 시작)
- 첫 번째 단계 진입율 35% → 55% 향상

---

### Phase 2 MDP (Minimum Delightful Product)

**반드시 포함:**
- AI 코치 대화 MVP (4가지 안전장치 필수 포함)
- 주간 이메일 서머리

**있으면 좋지만 필수 아님:**
- 카카오톡 알림톡 (이메일로 먼저 검증)
- 로드맵 부분 재생성
- .ics 캘린더 내보내기

**포함 안 함:**
- 팀 협업 기능
- 동적 벤치마크 (데이터 미축적)

**Phase 2 성공 기준:**
- AI 코치 대화 사용률 ≥ 40%
- 주간 재방문율(WAU/MAU) ≥ 35%
- MRR ≥ 500만원

---

### Phase 3 MDP (Minimum Delightful Product)

**반드시 포함:**
- 법령 변경 자동 알림 (해자의 핵심)

**있으면 좋지만 필수 아님:**
- 마이크로 가이드
- 정부지원사업 매칭

**포함 안 함:**
- 팀 협업 기능 (6개월 내 구현 금지)
- 네이티브 앱 (PWA로 충분)

**Phase 3 성공 기준:**
- MRR ≥ 2,000만원
- WAU/MAU ≥ 50%
- 법령 변경 알림 수신 후 재방문율 ≥ 70%
- NPS ≥ 55

## 6. Phase 전환 Go/No-Go 기준

### Phase 1 → Phase 2 전환 기준

| 지표 | Go 기준 | 현실적 측정 방법 |
|------|---------|----------------|
| Endowed Progress 적용률 | 배포 후 100% (기술 완료) | 배포 확인 |
| 준비도 스코어 표시 | 배포 후 100% | 배포 확인 |
| 첫 번째 단계 진입율 | ≥ 40% (생성 후 24시간 내) | 이벤트 트래킹 |
| 초기 이탈률 | 생성 직후 이탈 < 60% | 이벤트 트래킹 |
| 사용자 민원 (UX 혼란) | 0건 | CS 모니터링 |

> ⚠️ **No-Go 시나리오**: 첫 단계 진입율이 40% 미달이면 → UX 인터뷰 5건 진행 후 개선 Sprint 추가. Phase 2 착수 2주 연기.

---

### Phase 2 → Phase 3 전환 기준

| 지표 | Go 기준 | No-Go 액션 |
|------|---------|-----------|
| AI 코치 대화 사용률 | ≥ 40% | AI 코치 UX 개선 Sprint |
| AI 코치 법률 정확도 | ≥ 95% | 안전장치 강화 후 재측정 |
| WAU/MAU | ≥ 35% | 리텐션 강화 집중 Sprint |
| MRR | ≥ 300만원 (완화 기준) | 수익화 퍼널 점검 |
| 주간 이메일 오픈율 | ≥ 30% | 제목/내용 A/B 테스트 |
| AI 법률 오류 민원 | 0건 | **즉시 AI 코치 서비스 중단** |

> ⚠️ **중요 리스크**: AI 코치에서 잘못된 법률 정보 1건만 발생해도 서비스 신뢰도가 붕괴될 수 있다. Phase 2 중 AI 법률 정확도 모니터링은 **매일** 수행한다.

---

### Phase 3 중단 기준 (Kill Switch)

| 조건 | 조치 |
|------|------|
| K-Startup API 불안정 (가용성 < 99%) | 정부지원사업 매칭 기능 출시 연기 |
| ActionKit 업데이트 주기 불규칙 | 법령 변경 알림 수동 검수 레이어 추가 |
| MRR 성장이 2개월 연속 정체 | 수익화 전략 전면 재검토 |
