## Executive Summary

Step Zero는 ActionKit 법률 DB 기반의 **팩트-지능 분리 아키텍처**라는 구조적 해자를 보유하고 있으나, 현재 **"한 번 생성하고 끝나는 정적 리포트 생성기"**에 머물러 있다. 이 기획서는 Step Zero를 **"동적 창업 실행 코치"**로 전환하기 위한 16주(4개월) 통합 실행 계획이다.

### 핵심 전략 3축

1. **Phase 1 (Week 1-3)**: 비용 제로 Quick Win — 프론트엔드만으로 즉각적 UX 가치 전달
2. **Phase 2 (Week 4-8)**: ChatGPT 이탈 차단 — AI 코치 대화 MVP + 리텐션 엔진
3. **Phase 3 (Week 9-16)**: 경쟁사 불가능한 해자 — 법령 변경 자동 알림 + 성장 엔진

### 핵심 수치 목표

| 지표 | 현재 | P1 목표 | P2 목표 | P3 목표 |
|------|------|---------|---------|---------|
| WAU/MAU | — | 15% | 35% | 50% |
| 유료 전환율 | 0% | 측정 시작 | 5% | 8% |
| MRR | 0원 | — | 500만원 | 2,000만원 |
| AI 코치 사용률 | 0% | — | 40% | 60% |
| AI 법률 정확도 | — | — | ≥95% | ≥95% |

### 차별화 포지셔닝

> **"ChatGPT는 질문하면 답해주는 도구. Step Zero는 내 상황을 알고, 법이 바뀌면 먼저 알려주는 동반자."**

## 2. UX 개선 과제 상세 설계

### 2.1 Endowed Progress Effect (P0 / ★☆☆☆☆ / 3일)

**벤치마크**: LinkedIn 프로필 완성도 55% 향상 검증. Columbia/Drexel 연구 "78% vs 0% 출발점"에서 34% 완료율 향상.

**설계**:
- 회원가입 시 수집한 6개 필드(업종, 지역, 창업형태, 오픈시기, 예산, 관심분야)를 "이미 완료한 3단계"로 프레이밍
- 로드맵 생성 직후: **"18단계 중 3단계 이미 완료(17%)"** 표시
- 프로그레스 바를 17%에서 시작 (0%가 아님)

**적용 파일**: `RoadmapExecutionView.tsx`, `RoadmapSidebar.tsx`

**기대 효과**: 초기 이탈률 20-55% 감소 (LinkedIn 실증 기반)

**A/B 테스트**: Endowed Progress 17% vs 25% vs 33% 최적값 테스트

### 2.2 창업 준비도 5단계 스코어 (P0 / ★★☆☆☆ / 5일)

**설계**:
```
🌱 아이디어 → 📋 준비 착수 → 📝 서류 준비 중 → ✅ 인허가 완료 → 🚀 창업 준비 완료
```

- 진행률 원형 바에 현재 등급 + 5단계 트랙 표시
- 등급 업그레이드 시 토스트 알림 + 인사이트 카드
- Stripe Atlas "5단계 중 3단계 완료" 패턴 적용

**적용 파일**: `RoadmapSidebar.tsx`, `DashboardView.tsx`

### 2.3 다음 3-5 액션 집중 표시 (P0 / ★☆☆☆☆ / 2일)

**설계**:
- "지금 해야 할 일" 위젯: 현재 CHECKLIST 타입 액션 중 미완료 3-5개만 표시
- 완료 시 즉각 다음 액션 슬라이드인 (Todoist 패턴)
- 전체 로드맵은 "전체 보기" 토글로 접근
- Basecamp "Hill Chart" 영감: 현재 초점과 전체 조감을 분리

**적용 파일**: `RoadmapExecutionView.tsx`, `TimelineStepItem.tsx`

### 2.4 마일스톤 축하 모먼트 (P1 / ★★☆☆☆ / 5일)

**설계**:
- **위상(Phase) 완료 시**: 확정적 축하 모달 + 컨페티 애니메이션 + 인사이트 카드 + 등급 변화
- **개별 단계 완료 시**: 1/5 확률 랜덤 인사이트 카드 (Asana 변동비율 강화 스케줄)
- **인사이트 카드 예시**: "이 단계를 완료한 카페 창업자의 87%가 1주 내 다음도 완료했습니다"

**중요**: RPG 캐릭터 대신 전문적 업종별 인사이트 카드 (한국 B2B 맥락 적합)

**적용 파일**: `TimelineStepItem.tsx`, `TimelinePhaseCard.tsx`

### 2.5 사업체 성장 시각화 메타포 (P2 / ★★☆☆☆ / 3일)

- Forest App 패턴: 업종별 진행률 메타포 (카페: 🏗️설계도 → ☕오픈 준비 → 🎊그랜드오픈)
- 8개 우선 업종 먼저 구현, 그 외 default 메타포
- ⚠️ 조건부 적합: A/B 테스트 후 확대 여부 결정 권장

### 2.6 "첫 5분 경험" 최적화 (P1 / ★★☆☆☆ / 1주)

**설계**:
- `RoadmapChatIntake.tsx`: 각 답변 후 즉시 AI 정규화 확인 ("✅ 서울 강남구 카페로 설정합니다")
- 업종 입력 후 즉시: "평균 14단계, 약 72일 소요" 사전 예고
- 마지막 단계에서 전체 입력 요약 카드 + 수정 버튼
- `RoadmapGeneratingState.tsx`: 생성 stage별 의미 있는 메시지 + 업종 인사이트 슬라이딩 카드

## 3. AI 코치 대화 MVP 기술 설계

> 상세 문서: `docs/research/ai-coach-technical-design.md`

### 3.1 시스템 프롬프트 컨텍스트 빌더 (Jasper IQ 패턴)

**3개 레이어 구조**:

```
┌─────────────────────────────────────────────────────────┐
│  LAYER 1: 불변 팩트 레이어 (LLM 수정 불가)               │
│  • 업종, 지역, 창업형태, 오픈시기, 예산                  │
│  • 현재 단계 제목, 위상(phase), 목표(objective)          │
│  • LEGAL_BASIS 액션 (법령명 + ActionKit ID + source_url) │
│  • DOCUMENT 액션 (서류명 + source_url)                  │
│  → AI가 이 데이터를 생성·변형·추론할 수 없음              │
└─────────────────────────────────────────────────────────┘
          ↓ 주입
┌─────────────────────────────────────────────────────────┐
│  LAYER 2: 실행 상태 레이어 (현재 진행 상태)               │
│  • 완료된/미완료 CHECKLIST 액션 목록                      │
│  • estimated_days, step status, risk_notes              │
└─────────────────────────────────────────────────────────┘
          ↓ 주입
┌─────────────────────────────────────────────────────────┐
│  LAYER 3: 안내 레이어 (AI 행동 규칙)                     │
│  • 이전 대화 요약 (최근 5개 메시지)                       │
│  • 4가지 안전장치 규칙                                   │
│  • 응답 포맷 규칙 (인용 형식, 면책 고지)                  │
└─────────────────────────────────────────────────────────┘
```

**토큰 효율**: 최대 800-1,200 토큰 사용 (Claude claude-sonnet-4-6 200k 기준 여유)

### 3.2 SSE 스트리밍 엔드포인트

```
POST /api/v1/roadmaps/{roadmap_id}/steps/{step_id}/chat/stream
```

- **인증**: JWT 필수 (기존 `get_current_user` 재활용)
- **응답**: `text/event-stream`
- **이벤트 타입**: `token` / `sources` / `meta` / `error` / `done`
- **하트비트**: 15초마다 / 타임아웃: 30초

**SSE 이벤트 포맷**:
```
data: {"type": "token", "token": "위생교육은"}\n\n
data: {"type": "sources", "sources": [{"n": 1, "title": "식품위생법 제41조", ...}]}\n\n
data: {"type": "meta", "thread_id": "uuid-...", "message_id": 42}\n\n
data: {"type": "done"}\n\n
```

### 3.3 대화 이력 DB 스키마 (신규)

기존 RAG(curai) 도메인과 **완전 분리** (브레인스토밍 합의 — 로드맵 컨텍스트 주입 구조가 curai와 다름):

```python
class RoadmapChatThread(SQLModel, table=True):
    id: UUID
    roadmap_id: UUID       # FK → roadmap.id
    step_id: int           # FK → roadmapstep.id
    user_id: int           # FK → user.id
    created_at: datetime
    # 복합 인덱스: (roadmap_id, step_id, user_id)

class RoadmapChatMessage(SQLModel, table=True):
    id: int
    thread_id: UUID        # FK → roadmap_chat_threads.id
    role: str              # "user" | "assistant"
    content: str           # sa.Text
    sources_json: list[dict]  # [{n, title, url, actionkit_id}]
    is_truncated: bool     # 연결 끊김으로 부분 저장된 경우
    created_at: datetime
```

### 3.4 할루시네이션 방지 4가지 안전장치

| # | 패턴 | 구현 | 근거 |
|---|------|------|------|
| 1 | **Harvey AI**: 팩트-지능 분리 | LAYER 1 불변 팩트 섹션 — ActionKit 데이터만 사용 | Harvey AI 0.2% 환각률 달성 |

### 4.1 3-Tier 구독 모델

2. 실시간 한국 법령 모니터링 파이프라인 없음
3. 영향받는 개인 로드맵 역추적 쿼리 불가

**LegalZoom 벤치마크**: 90,000개 관할권 규제 변경 모니터링 → 구독 매출 13% 성장

```
        │
        ▼
[영향받는 RoadmapStepAction 역추적]
  metadata_json.actionkit_item_id 기반 JOIN
        │
        ▼
[영향받는 Roadmap → team_id → user 조회]
        │
        ▼

  "식품위생법 제37조 변경 → 위생교육 4시간→8시간"
        │
        ▼

  Pro: 카카오톡 + 이메일 즉시
  Starter: 이메일 + 로그인 시 배지
  Free: 로그인 시 배지만 (Pro 업그레이드 CTA)
        │
```


### 9.2 업종별 벤치마크 인사이트

**최소 데이터 볼륨**: 업종별 N≥30이면 통계적 유의미

**인사이트 예시**:
1. "카페 창업자의 87%가 이 단계에서 어려움을 느꼈습니다"
2. "같은 업종 평균보다 2일 빠릅니다"
3. "이 단계를 마친 창업자의 78%가 세무사 미리 선정 시 2주 단축"
4. "서울 강남구 카페 창업자 평균 72일, 현재 43일째 (상위 31%)"
5. "위생교육 수료까지 평균 14일, 소방교육까지 평균 7일"

**초기 전략**: 데이터 축적 전 정적 벤치마크 → N≥30 달성 후 동적 벤치마크로 전환

### 9.3 A/B 테스트 프레임워크

| 테스트 | 변형 | 최소 표본 | 성공 지표 |
|--------|------|---------|---------|
| Endowed Progress | 17% vs 25% vs 33% | 업종당 30명 | 첫 단계 진입율 |
| 스트릭 주기 | 주간 vs 격주 | 100명/그룹 | 4주 리텐션 |
| 페이월 포인트 | 법적 근거 3개 vs 5개 무료 | 200명/그룹 | 유료 전환율 |
| 이메일 제목 | "진행 현황" vs "할 일 추천" vs "마감 임박" | 500명/그룹 | 오픈율 |

**인프라**: 해시 기반 사용자 분배 (user_id % 100), p-value < 0.05 판단 기준

### 9.4 B2B 데이터 상품화 로드맵

| 데이터 상품 | 시기 | 대상 | 가격 |

## 10. 리스크 분석 및 대응 매트릭스

### 10.1 법적 리스크 (최고 우선)

#### 변호사법 제109조 — "법률 사무" vs "정보 안내" 경계

- **안전**: "식품위생법 제41조에 따르면 위생교육이 필요합니다"
- **위험**: "귀하의 경우 위생교육 면제 대상에 해당합니다"
- **위험 경계**: "이 법령을 귀하의 특수 상황에 어떻게 적용할지"

**구조적 방어 3가지** (면책 문구만으로는 부족):
1. ActionKit에 없는 정보는 기술적으로 생성 불가하게 차단
2. "귀하의 경우"를 포함하는 응답 패턴 시스템 필터링
3. 복잡한 케이스는 AI가 판단 중단 → 행정사/법무사 연결 강제

#### AI 기본법(2026.01 시행) — 라벨링 의무

모든 AI 코치 응답에 "이 답변은 AI가 생성했습니다" 표시 **법적 의무**. 현재 기획의 "하단 고정 면책 문구"가 AI 기본법 라벨링 요건을 충족하는지 **법무 검토 필수**.

#### NYC MyCity 챗봇 교훈

인허가 요건 잘못 안내 → 창업자 영업 시작 → 단속 → 폐업. 이 경우 "면책 문구 안내"는 법원에서 방어 불가할 수 있다.

**최우선 행동**: AI 코치 기획 확정 즉시 → 법률 자문 착수 (변호사법 + AI 기본법, 예상 50-150만원)

### 10.2 ChatGPT/Gemini 추격 시나리오

| 요소 | ChatGPT/Gemini | Step Zero | 격차 |
|------|---------------|-----------|------|
| 한국 법률 정확 인용 | ~57% (Stanford) | >95% (ActionKit) | **+38%p** |

| 개별 로드맵 추적 | 불가능 | 핵심 기능 | **구조적** |
| 업종별 DB | 없음 | ActionKit 8개 업종 | **현재 우위** |

**핵심 위협**: ChatGPT가 한국 법령 전문 데이터를 자체 훈련하거나 로펌과 파트너십 체결하는 시나리오. LegalZoom-OpenAI 제휴(2023) 선례 존재. → ActionKit 업종 확대 가속화 + 사용자 데이터 해자 구축으로 대응.

### 10.3 ActionKit 커버리지 한계

IT 업종은 상위 3위 창업 업종. IT 창업자가 fallback을 받으면 즉각 이탈 + 부정 후기.

4. 제조업 (복잡도 최상, 마지막)
