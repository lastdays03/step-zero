# StepZero 발표 슬라이드

## 실행 방법

```bash
# 1. 프로젝트 폴더로 이동
cd stepzero-slides

# 2. 의존성 설치
npm install

# 3. 개발 서버 실행
npx slidev --open

# 4. PDF로 내보내기 (선택)
npx slidev export
```

## 파일 구조

```
stepzero-slides/
├── package.json      # 프로젝트 설정
├── slides.md         # 슬라이드 본문 (17장)
└── README.md         # 이 파일
```
