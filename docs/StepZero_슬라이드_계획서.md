# StepZero 발표 슬라이드 계획서

> 대상: 창업 경진대회 / 분량: 10~15분 (18장) / 도구: Slidev

---

## Part A. 기획안 보완점 분석

현재 기획안은 서비스의 구조와 차별화 전략이 잘 정리되어 있지만, **창업 경진대회 발표** 관점에서 다음 항목들이 보완되어야 심사위원을 설득할 수 있습니다.

### 1. 시장 규모 데이터 부재 (TAM/SAM/SOM)

현재 기획안에 시장 규모를 뒷받침하는 숫자가 전혀 없습니다. 심사위원은 "이 시장이 얼마나 큰가?"를 가장 먼저 봅니다.

**보완 방향**: 예비 창업자 수(연간 약 150만 명 관심 표명, 실제 신규 사업자 약 100만 건/년), 소상공인 시장 규모, 창업 교육/컨설팅 시장 규모 등을 리서치하여 TAM → SAM → SOM 퍼널을 구성해야 합니다.

### 2. 수익 모델(Revenue Model) 미기재

기획안 어디에도 "어떻게 돈을 벌 것인가"가 없습니다. 경진대회에서 사업의 지속가능성을 판단하는 핵심 항목입니다.

**보완 방향**: 프리미엄 구독(월 9,900원~), B2B 파트너 수수료, 지원사업 매칭 수수료 등 수익원을 명시하고, 3년차 예상 매출 시나리오를 그려야 합니다.

### 3. 경쟁사 구체적 비교 부족

범용 챗봇과 기존 커뮤니티만 언급했지만, 실제 경쟁 환경에 있는 구체적인 서비스(K-Startup, 창업진흥원, 캐시노트, 자비스 등)와의 포지셔닝 맵이 필요합니다.

**보완 방향**: 2x2 포지셔닝 맵(축: AI 자동화 정도 × 커뮤니티 밀도)으로 시각화하면 차별점이 명확해집니다.

### 4. 팀 소개 없음

창업 경진대회에서 "이 팀이 이걸 해낼 수 있는가?"는 결정적인 평가 요소입니다.

**보완 방향**: 팀원별 역할과 핵심 역량, 관련 경험을 1장으로 정리해야 합니다.

### 5. KPI / 핵심 성과지표 부재

실행 로드맵은 있지만, 각 Phase별 "무엇을 얼마만큼 달성할 것인가"가 없습니다.

**보완 방향**: Phase별 핵심 KPI를 제시해야 합니다. 예를 들어 MVP 단계에서 MAU 1,000명, 로드맵 생성 5,000건, 완주율 30% 등의 수치 목표가 필요합니다.

### 6. 구체적인 유저 시나리오/데모 부족

서비스 흐름이 개념적으로만 설명되어 있어, 실제로 사용자가 어떤 화면을 보게 되는지 상상하기 어렵습니다.

**보완 방향**: "반려동물 수제 간식 창업"이라는 구체적 시나리오로 Step 0→1→2→3 전체를 걸어보는 데모 플로우가 있으면 발표 임팩트가 크게 올라갑니다.

### 7. 기술 구현 방안 추상적

"LLM + RAG"라는 키워드만 있고, 어떤 데이터를 수집하고, 어떻게 파이프라인을 구성하는지 구체성이 부족합니다.

**보완 방향**: 법령 DB(국가법령정보센터) + 지원사업 공고(K-Startup) 크롤링 → 벡터 DB 저장 → LLM 쿼리 → 팩트체크 레이어 등 기술 아키텍처를 간략히 보여줘야 합니다.

### 8. 법적 리스크 대응 없음

AI가 행정/법률 관련 조언을 하는 서비스이므로, 면책 조항이나 규제 대응 방안이 필요합니다.

**보완 방향**: "법률 자문이 아닌 정보 가이드", 출처 원문 링크 제공, 전문가 연결 안내 등의 대응 방안을 간략히 언급해야 합니다.

#### Slide 2: Hook (quote)
```

```
- 실제 예비 창업자들의 질문 3개를 v-click으로 하나씩 등장

## Part C. 종만님이 준비해야 할 것 (Action Items)

슬라이드 제작에 들어가기 전, 아래 항목을 확인/준비해주세요:

1. **시장 규모 데이터**: TAM/SAM/SOM 수치 리서치 (통계청, 중소벤처기업부 자료)
2. **수익 모델 확정**: 구독료 / 수수료 / 기타 수익원과 예상 단가
3. **경쟁사 리스트**: 실제 비교하고 싶은 서비스 3~5개
4. **팀 정보**: 멤버별 이름, 역할, 핵심 역량
5. **UI 목업 또는 와이어프레임**: 있으면 슬라이드 퀄리티가 크게 올라감
6. **MVP 현황**: 프로토타입이 있다면 스크린샷, 없다면 와이어프레임이라도
7. **3년 재무 전망**: 간단한 매출/비용 시나리오
