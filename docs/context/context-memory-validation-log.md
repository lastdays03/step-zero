1. `성공=1`, `부분성공=0.5`, `실패=0`으로 환산한다.
2. `(합계 / 총 기록 수) * 100`으로 계산한다.
- 누락 정보 유형 상위 2개:
1. `없음`은 빈도로 집계하지 않는다.
2. 동일 빈도일 경우 최근 날짜에 발생한 유형을 우선한다.
