# NotebookLM Query Templates

목적: 프로젝트 자료 탐색/분석 결과를 실행 문서(L1)에 반영하기 위한 표준 질의 템플릿을 유지한다.

## A. 결정 근거 재확인
- 질문 템플릿:
`이 주제(<주제명>)에 대해 기존 합의/결정 근거를 문서 출처와 함께 요약해줘. 대안이 기각된 이유도 포함해줘.`
- 반영 대상:
1. `docs/context/decisions.md`
2. `docs/planning/*`

## B. 대안 비교
- 질문 템플릿:
`옵션 A/B/C를 성능, 복잡도, 운영비용, 리스크 기준으로 비교하고 현재 프로젝트 상황에서 권장안을 제시해줘.`
- 반영 대상:
1. `docs/planning/*`
2. `docs/context/dev-status.md`

## C. 디버깅 근거 추출
- 질문 템플릿:
`현재 이슈(<오류/증상>)의 원인 후보를 근거 문서 기준으로 우선순위화하고, 재현/검증 절차를 제안해줘.`
- 반영 대상:
1. `docs/context/dev-status.md`
2. 필요 시 이슈/PR 문서

## D. 보안 점검 체크리스트 생성
- 질문 템플릿:
`현재 변경 범위(<모듈/기능>) 기준으로 점검해야 할 보안 항목 체크리스트를 생성해줘. 우선순위와 근거를 함께 제시해줘.`
- 반영 대상:
1. `docs/planning/*`
2. `docs/context/dev-status.md`
