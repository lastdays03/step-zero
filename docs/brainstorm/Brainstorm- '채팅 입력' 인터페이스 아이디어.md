## 🧠 Brainstorm: 채팅 입력 및 RAG 연동 UX 아이디어

### Context
사용자는 **StepZero**가 보유한 방대한 산업/업종 정보(RAG)를 채팅창에서 자연스럽게 검색하고 선택할 수 있는 UX를 원합니다. 핵심은 **"입력은 쉽고, 선택은 직관적이어야 하며, 데이터 기반의 현명한 의사결정"**을 돕는 것입니다.

---

### Option A: "실시간 컨텍스트 자동완성 (The Smart Input)"
**사용자가 타이핑하는 순간, RAG가 관련 업종을 찾아 '태그' 형태로 추천하는 방식**

*   **동작 방식**:
    1.  사용자가 "카페 창업..."이라고 입력.
    2.  입력창 상단에 실시간으로 `[프랜차이즈 카페]`, `[개인 카페]`, `[무인 카페]` 칩(Chip)이 뜹니다.
    3.  사용자가 칩을 클릭하면 해당 컨텍스트가 채팅창에 고정(`Pinned Context`)됩니다.
    4.  이후 대화는 선택된 업종 데이터를 기반으로 진행됩니다.

✅ **Pros:**
- **속도**: 별도의 검색 단계 없이 대화 흐름 속에서 자연스럽게 컨텍스트 설정 가능.
- **발견성**: 사용자가 미처 생각하지 못한 세부 업종을 RAG가 먼저 제안해 줌.

❌ **Cons:**
- **기술적 부하**: 실시간 검색(Search-as-you-type) 구현 필요.
- **화면 복잡도**: 모바일 화면에서 키보드와 추천 칩이 겹쳐서 불편할 수 있음.

📊 **Effort:** Medium (프론트엔드 인터랙션 중요)

---

### Option B: "인터랙티브 카드 & 선택지 (The Intelligent Clarification)"
**사용자의 모호한 입력을 AI가 먼저 분석한 후, '카드 형태'로 역제안하는 방식**

*   **동작 방식**:
    1.  사용자: "카페 하고 싶어." (전송)
    2.  AI 컨설턴트: "카페 창업과 관련하여 다음과 같은 구체적인 데이터가 준비되어 있습니다. 어떤 방향을 고려 중이신가요?" 라고 말하며,
    3.  채팅 말풍선 아래에 **3장의 데이터 요약 카드(Card UI)**를 보여줍니다.
        *   `카드 1: 저가형 테이크아웃 (매출 데이터 요약)`
        *   `카드 2: 대형 베이커리 카페 (초기 비용 요약)`
        *   `카드 3: 스터디 카페 (운영 난이도 요약)`
    4.  사용자가 카드를 '선택'하면 해당 데이터가 로드됩니다.

✅ **Pros:**
- **정확한 매칭**: 사용자의 의도를 명확히 파악한 후, 그에 맞는 가장 적합한 데이터를 제공할 수 있음.
- **전문성 강조**: 단순 대화가 아니라, "구체적인 데이터를 근거로 제안한다"는 신뢰감 형성.
- **정보 전달력**: 단순 텍스트보다 카드 UI(이미지+요약)로 업종 특징을 한눈에 파악 가능.

❌ **Cons:**
- **대화 끊김**: 즉답을 원하는데 굳이 선택지를 주는 것이 번거로울 수 있음.
- **RAG 정확도 의존**: 사용자 의도와 다른 카드를 추천하면 신뢰도 하락.

📊 **Effort:** High (카드 UI 및 동적 렌더링 필요)

---

### Option C: "사전 진단 위젯 (The Pre-Chat Form)"
**채팅 시작 전, 혹은 입력창 옆 '진단 버튼'을 통해 명확한 조건을 먼저 설정하는 방식**

*   **동작 방식**:
    1.  입력창 좌측 `+` 버튼을 누르면 '업종 찾기' 메뉴가 뜹니다.
    2.  작은 팝업/모달에서 키워드로 RAG 데이터를 검색합니다. (예: "치킨")
    3.  검색 결과 리스트(`BBQ`, `교촌`, `개인 브랜드`) 중 하나를 선택하여 채팅창에 첨부합니다.
    4.  첨부된 상태에서 질문을 입력합니다. ("이 브랜드 예상 수익률 어때?")

✅ **Pros:**
- **정확성**: 사용자가 가장 원하는 데이터를 명확하게 지정하고 시작할 수 있음.
- **데이터 구조화**: 질문의 의도가 명확해져 AI 답변 품질이 향상됨.

❌ **Cons:**
- **진입 장벽**: 사용자가 뭔가 '작업'을 해야 한다는 부담감 (귀찮음).
- **유연성 부족**: 대화 도중 주제를 바꾸려면 다시 첨부 파일을 바꿔야 함.

📊 **Effort:** Low (기존 파일 첨부 UX와 유사)

## 💡 Recommendation

**Option B (인터랙티브 카드) 수정안**

**결론:**
기존의 "PT 코치" 컨셉은 다소 강압적이거나 가벼워 보일 수 있습니다. 대신 **"Intelligent Data Consultant (지능형 데이터 컨설턴트)"**로서의 정체성을 강화해야 합니다. AI는 사용자의 의도를 파악하고, **가장 적합한 데이터(업종)를 큐레이션하여 선택권을 주는 파트너** 역할을 해야 합니다.

**구체적 실행:**
1.  **초기**: 사용자의 모호한 질문 → RAG 검색 → **카드 캐러셀(Carousel)** UI로 3개의 유력 후보 제시.
2.  **데이터 중심**: 각 카드는 감상적인 문구보다는 **핵심 데이터(비용, 수익률 등)**를 요약하여 보여줍니다.
3.  **UI 톤앤매너**: 깔끔하고 전문적인 비즈니스 툴의 느낌을 유지합니다.
